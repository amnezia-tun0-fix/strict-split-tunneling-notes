# Security policy

If you find a vulnerability in the strict split tunneling fix (the `uidfilter` package in
amneziawg-go, the JNI bridge in amneziawg-android, the setting in amnezia-client) or in the
test builds published by this organization, please report it privately first.

**How:** open the **Security** tab of the affected repository and press
**Report a vulnerability**. Private vulnerability reporting is enabled on every repository of
`amnezia-tun0-fix`; the report is visible only to the maintainers. If you are not sure which
repository it belongs to, use this one.

Please do not open a public issue for a vulnerability that is not fixed yet. We will answer
within a few days, say whether we can reproduce it, and agree with you on when to publish.

The test builds are not official AmneziaVPN releases. A problem in AmneziaVPN code that our
changes do not touch belongs to the upstream project, `github.com/amnezia-vpn`.
